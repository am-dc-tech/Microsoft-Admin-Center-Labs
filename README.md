# Microsoft Admin Center Labs

Hands-on help desk labs in the Microsoft 365 Admin Center. Each ticket is a realistic user issue, worked from report to resolution with screenshots and documentation.

## Tickets

| # | Ticket | Issue | Focus |
|---|--------|-------|-------|
| 001 | [Pablo: License Escalation](./tkt-001-pablo-license-escalation) | Missing or incorrect license assignment | Licensing |
| 002 | [Tracy: Password Reset](./tkt-002-tracy-password-reset) | User locked out by a forgotten password | Password reset |
| 003 | [Jamie: Cannot Sign In](./tkt-003-jamie-cannot-sign-in-error-at-login) | Sign-in error at login | Account lockout |

## Skills Demonstrated

- User and license management in Microsoft 365 Admin Center
- Password resets and account unlocks
- Troubleshooting sign-in errors
- Clear ticket documentation and communication

## Tools

Microsoft 365 Admin Center · Microsoft Entra ID

## Structure

Each ticket folder contains the issue summary, troubleshooting steps, resolution, and screenshots.
